What Wisp does

Wisp is a timid ghost who looks at a short JavaScript snippet you paste. A check in the browser marks a few kinds of risky lines. Gemma, running on this computer, explains only those marked lines. A clean snippet never calls the model, and she does not invent a finding.

She looks at the text in the box. She does not scan a repository or a GitHub account.

Look at a snippet

  1. Paste a short JavaScript snippet.
  2. Press Look at this.
  3. She reads it in the browser. If nothing is marked, she looks relieved and the page says “Nothing marked.”
  4. If a line is marked, she looks worried. The check writes the line, a safer rewrite, and a citation. Gemma then explains that line in her voice.

An empty box leaves her idle. She says “Paste a snippet first.” The mood buttons change her face, and pressing one cancels a look that is still in progress.

What she marks

Four checks. Each one owns its safer line and its citation. Gemma does not choose a different fix. Comments are skipped, including a // comment, and :// is left intact.

  • A string run as code. eval(...) or new Function(...). Safer: result = allowedAction(input); Citation: MDN: eval.
  • Text turned into HTML. An assignment to innerHTML, or a call to document.write or document.writeln. Safer: element.textContent = text; Citation: MDN: Element.innerHTML.
  • A secret kept in the code. A name such as api key, secret, password, or token, with a quoted value at least 8 characters long. Placeholder values, such as example, changeme, or the word password, are left alone. Safer: const apiKey = process.env.API_KEY; Citation: OWASP: Secrets Management Cheat Sheet.
  • A script loaded over plain HTTP. A script address that uses http://. Safer: that same line with https://. Citation: MDN: Mixed content.

When Gemma speaks

The page asks Ollama at http://127.0.0.1:11434. It tries gemma4:e4b, then gemma4:e2b if the first model is missing. The weights stay on this computer. Cloud tags are not used.

Gemma is asked to explain the marked line in two or three short sentences, to include that line’s citation URL, and to mention no other line number. She is also asked not to describe an attack, a payload, or a different fix.

Her reply stays on the page only when it includes that citation URL and every “line N” she names is a line the check marked. Otherwise the page says “Wisp kept the checker’s words.” If she does not answer, it says “Wisp kept the checker’s words. Gemma did not answer.” The safer line and the citation remain either way.

If she cannot reach Gemma

Ollama needs to be running on this computer, with one of those two models pulled. If the browser blocks the call, quit Ollama, set OLLAMA_ORIGINS to the origin of this page (http://127.0.0.1:8772 for the local preview), and start Ollama again.
